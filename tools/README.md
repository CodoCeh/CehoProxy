# Инструменты для проверки

Только для разработки и лаборатории. В выпуск не входят.

| Что | Команда | Что делает |
|---|---|---|
| Дымовой тест первой настройки | `python3 tests/smoke/setup_smoke.py` | Проверяет то, что вызывают установщики: `setup --sub`, `--app`, `add-app all`, `detect-apps`. Настройки во временной папке. Идёт в CI на Windows, macOS и Linux. |
| Обновление лаборатории | `tools/lab/update-all.sh [машина ...]` | Обновляет машины параллельно до последнего выпуска, ждёт защиту и печатает таблицу «версия, защита». Машины: laptop, server2019, win11, debian, ubuntu, mini, ws2016. |
| Запуск виртуалки на ноутбуке | `tools/lab/start-vm.sh <ВМ> [--make-room]` | Отказывает, если сумма памяти работающих ВМ вместе с новой больше 10 ГБ. С `--make-room` сохраняет состояние других лабораторных ВМ. Пятая ВМ без этого вешает ноутбук: панель CehoProxy на нём перестаёт отвечать. |
| Проверка панели кликами | `tools/ui/.venv/bin/python tools/ui/panel_check.py http://127.0.0.1:8899 [--shots папка]` | Chrome проходит вкладки, тему, режимы, ошибочные формы, журнал, узкий экран. Состояние не меняется. Работает на русском и английском интерфейсе, язык берётся со страницы. |

Подготовка проверки панели один раз:

```bash
python3 -m venv tools/ui/.venv && tools/ui/.venv/bin/pip install -r tools/ui/requirements.txt
```

Панель слушает только `127.0.0.1`, поэтому проброс порта делайте на тот же номер: `ssh -f -N -L 8899:127.0.0.1:8899 <машина>`.

Не запускайте проверку панели на рабочем ноутбуке владельца.
