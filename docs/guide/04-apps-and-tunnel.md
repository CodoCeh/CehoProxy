# Программы и туннель

CehoProxy не включает VPN на весь компьютер. Вы выбираете программы, и только они выходят в интернет через туннель. Всё остальное идёт как раньше.

## Как это работает

- Выбранная программа выходит в интернет только через VPN.
- Если VPN не отвечает, у неё пропадает интернет. Прямой выход не включается: ваш настоящий адрес не утечёт.
- Остальные программы не меняются. Браузер, банк и всё, что вы не добавили, работают как обычно.

## Как добавить программу

1. Откройте вкладку **Программы**.
2. Выберите один из способов:
   - **«Добавить все»** в блоке «Рекомендуем»: CehoProxy нашла на компьютере программы, которым обычно нужен VPN (например, ИИ-инструменты), и предлагает отправить их все сразу.
   - **Каталог программ**: найдите программу в списке и нажмите «+». Каталог можно искать по названию.
   - **«Выбрать программу»**: если программы нет в каталоге, выберите её файл вручную.
3. Вернитесь на **Состояние** и нажмите «Включить».
4. **Перезапустите добавленные программы.** Открытая программа продолжает старые соединения, новые правила действуют только на новые.

Сохранение программы не включает VPN. Это два разных действия: сначала вы выбираете, потом включаете.

## Как проверить, что программа в туннеле

На вкладке **Программы** рядом с программой виден счётчик соединений. В блоке «Проверка трафика» CehoProxy сверяет, что соединения программы идут именно через туннель.

Если появилось сообщение «Обнаружен прямой трафик», читайте [«Прямой трафик и „Исправить все“»](07-direct-traffic.md).

В терминале то же делает команда:

```bash
chp verify
```

## Программы из командной строки

Некоторые инструменты запускаются коротким именем в терминале (`codex`, `claude`), а не значком. Добавляйте такой инструмент по пути к файлу программы. Его вспомогательные процессы CehoProxy берёт в туннель сама.

## Как убрать программу из туннеля

Нажмите на программе «Убрать» на вкладке **Программы**. Правило брандмауэра на Windows для неё снимается, программа снова работает напрямую.

## Ваша страна: свои сайты напрямую

На вкладке **Программы** есть блок «Ваша страна». Выберите страну, в которой находитесь. Сайты и адреса этой страны программы из туннеля будут открывать напрямую, без VPN, а всё остальное пойдёт через VPN. Так работают местные банки, госуслуги и магазины, которые не пускают зарубежные адреса.

Для России напрямую идут все сайты в зонах .ru, .рф, .su, .рус, .москва, .дети, .moscow и .tatar, а также известные российские сайты и IP-адреса в других зонах. Для Китая и Ирана список включает домены и IP-адреса, для остальных стран только IP-адреса. Это не значит, что напрямую пойдут все сайты страны. Если вашей страны нет в списке, выберите «Другая страна»: тогда всё идёт по вашим правилам. Пока туннель включён, после выбора нажмите «Применить».

## Другая страна для одной программы

Некоторые сервисы (например, Gemini и Antigravity) не принимают часть серверов. Для такой программы можно выбрать отдельный сервер в её карточке. Пока ничего не выбрано, программа использует общий пул серверов.

## То же в терминале

```bash
chp add-app             добавить программу (покажет найденные)
chp add-app all         отправить в туннель все найденные рекомендуемые
chp no-internet 2       выключить второй программе интернет совсем
chp countries           страны выхода, галочками
chp node                серверы по одному
```
