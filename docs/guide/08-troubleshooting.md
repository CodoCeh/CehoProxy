# Если что-то не работает

Начните с первой строки таблицы. Каждая следующая строка нужна, только если предыдущая не помогла.

| Что видите | Что сделать |
|---|---|
| Что угодно непонятное | Выполните `chp doctor`. Он осмотрит всю цепочку и напишет, что исправить. Часть проблем чинится сама: `sudo chp doctor fix` (на Windows `chp doctor fix` в PowerShell от администратора). В панели то же на вкладке «Проверка». |
| Туннель включён, но программа без интернета | Перезапустите программу. Если подписка не отвечает, у выбранных программ нет интернета по замыслу: это защита от утечки. Проверьте подписку на вкладке «Подписки». |
| Программа показывает мой настоящий адрес | Перезапустите программу. Затем [«Прямой трафик»](07-direct-traffic.md). |
| Подписка не добавляется | [«Как добавить подписку»](03-add-subscription.md), раздел «Если ссылка не принимается». |
| Сайт или сервис пишет «недоступно в вашем регионе» | Для программы можно выбрать другую страну: вкладка «Программы», карточка программы. Или выберите страны выхода: `chp countries`. |
| Панель не открывается | `chp status`. Если служба не работает, `chp doctor fix`. |
| Не запускается Light | [Раздел про Light](05-light.md#если-окно-не-открывается). |
| Движок не скачался | `sudo chp engine` (на Windows `chp engine` от администратора). |

## Что приложить к сообщению о проблеме

В панели на вкладке «Помощь» есть «Отчёт для поддержки». Он создаётся только на вашем устройстве и никуда не отправляется. Пароли, ссылки подписок, адреса, имена и пути в нём скрыты. Перед тем как передать отчёт, посмотрите предпросмотр.

Сообщить о проблеме: [GitHub: обсуждение](https://github.com/CodoCeh/CehoProxy/issues). Приложите отчёт или вывод `chp doctor` и `chp status`.
