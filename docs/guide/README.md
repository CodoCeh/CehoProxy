# Руководство CehoProxy

Пошаговые инструкции для тех, кто видит программу впервые. Терминал нужен только там, где это сказано прямо.

CehoProxy отправляет в VPN только выбранные программы. Остальные программы работают как обычно, через ваш обычный интернет.

## Три слова, которые встретятся

- **Подписка** — одна ссылка от вашего VPN-сервиса. По ней CehoProxy сама скачивает список серверов и обновляет его. Своих подписок CehoProxy не выдаёт: вы приносите свою.
- **Туннель** — защищённый путь до сервера VPN. Через него идёт трафик выбранных программ.
- **Выход** — страна и адрес, под которыми сайты видят вашу программу.

## Где что лежит

- Панель на компьютере: `http://127.0.0.1:8899`. Откроется командой `chp open`. Снаружи она недоступна, только с этого компьютера.
- Все команды терминала: `chp help`.
- Сообщить о проблеме: [обсуждение на GitHub](https://github.com/CodoCeh/CehoProxy/issues). Приложите вывод `chp doctor` и `chp status`.
